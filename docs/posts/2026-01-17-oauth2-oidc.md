# OAuth 2.0 与 OIDC：授权与认证协议详解

<div class="post-meta">📅 2026-01-17 &nbsp;·&nbsp; 🏷️ <span class="tag">安全</span> <span class="tag">OAuth</span></div>

OAuth 2.0 是授权协议，OIDC（OpenID Connect）在其上增加了身份认证能力，是现代 SSO 的基础。

---

## 一、OAuth 2.0 核心概念

```
角色：
- Resource Owner（资源所有者）── 用户
- Client（客户端）           ── 应用程序（你开发的 App）
- Authorization Server       ── 授权服务器（微信、GitHub、自建）
- Resource Server            ── 资源服务器（API 服务）

核心流程（Authorization Code Flow）：
1. 用户点击"微信登录"
2. 重定向到微信授权页
3. 用户同意授权
4. 微信回调 App，携带 authorization_code
5. App 用 code 换取 access_token（后端对后端，安全）
6. App 用 access_token 调用微信 API 获取用户信息
```

---

## 二、四种授权模式

```
1. Authorization Code（授权码模式）
   适用：服务端 Web 应用、移动 App（配合 PKCE）
   最安全，最常用

2. Implicit（隐式模式）
   适用：纯前端 SPA（已废弃，改用 PKCE）
   
3. Client Credentials（客户端凭证）
   适用：机器对机器（M2M），无用户参与
   如：微服务间调用、定时任务访问 API

4. Resource Owner Password（密码模式）
   已废弃，不推荐使用
```

## 三、Spring Authorization Server 实现

```java
// pom.xml
<dependency>
    <groupId>org.springframework.security</groupId>
    <artifactId>spring-security-oauth2-authorization-server</artifactId>
    <version>1.2.1</version>
</dependency>
```

```java
@Configuration
public class AuthorizationServerConfig {

    // 注册客户端（实际项目存数据库）
    @Bean
    public RegisteredClientRepository registeredClientRepository() {
        RegisteredClient webClient = RegisteredClient
            .withId(UUID.randomUUID().toString())
            .clientId("web-client")
            .clientSecret("{bcrypt}" + passwordEncoder().encode("secret"))
            .clientAuthenticationMethod(ClientAuthenticationMethod.CLIENT_SECRET_BASIC)
            .authorizationGrantType(AuthorizationGrantType.AUTHORIZATION_CODE)
            .authorizationGrantType(AuthorizationGrantType.REFRESH_TOKEN)
            .redirectUri("http://localhost:3000/callback")
            .scope(OidcScopes.OPENID)
            .scope(OidcScopes.PROFILE)
            .scope("order:read")
            .tokenSettings(TokenSettings.builder()
                .accessTokenTimeToLive(Duration.ofMinutes(30))
                .refreshTokenTimeToLive(Duration.ofDays(7))
                .reuseRefreshTokens(false)
                .build())
            .build();
        return new InMemoryRegisteredClientRepository(webClient);
    }

    // JWT 签名密钥
    @Bean
    public JWKSource<SecurityContext> jwkSource() {
        RSAKey rsaKey = Jwks.generateRsa();
        JWKSet jwkSet = new JWKSet(rsaKey);
        return new ImmutableJWKSet<>(jwkSet);
    }
}
```

## 四、OIDC：在 OAuth 上叠加身份认证

```
OAuth 2.0：Who can access what（授权）
OIDC：Who are you（认证）

OIDC 在 OAuth 基础上增加了：
- scope=openid
- ID Token（JWT，包含用户身份信息）
- /userinfo 端点

ID Token 示例：
{
  "iss": "https://auth.example.com",  // 颁发者
  "sub": "24400320",                   // 用户唯一标识
  "aud": "web-client",                 // 客户端 ID
  "exp": 1311281970,
  "iat": 1311280970,
  "name": "张三",
  "email": "zhangsan@example.com",
  "picture": "https://..."
}
```

## 五、客户端集成（Spring Boot）

```java
// pom.xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-oauth2-client</artifactId>
</dependency>
```

```yaml
# application.yml
spring:
  security:
    oauth2:
      client:
        registration:
          # 接入 GitHub
          github:
            client-id: ${GITHUB_CLIENT_ID}
            client-secret: ${GITHUB_CLIENT_SECRET}
            scope: user:email
          # 接入自建 OIDC 服务
          my-auth-server:
            client-id: web-client
            client-secret: secret
            authorization-grant-type: authorization_code
            redirect-uri: "{baseUrl}/login/oauth2/code/{registrationId}"
            scope: openid,profile
        provider:
          my-auth-server:
            issuer-uri: https://auth.example.com
```

```java
@RestController
public class UserController {
    
    @GetMapping("/me")
    public Map<String, Object> currentUser(@AuthenticationPrincipal OidcUser user) {
        return Map.of(
            "name", user.getFullName(),
            "email", user.getEmail(),
            "sub", user.getSubject()
        );
    }
}
```

## 六、机器对机器（Client Credentials）

```java
// 微服务间调用：无用户，Client 直接获取 Token
@Configuration
public class ResourceServerConfig {
    @Bean
    public WebClient webClient(OAuth2AuthorizedClientManager clientManager) {
        var oauth2Client = new ServletOAuth2AuthorizedClientExchangeFilterFunction(clientManager);
        oauth2Client.setDefaultClientRegistrationId("order-service");
        return WebClient.builder().apply(oauth2Client.oauth2Configuration()).build();
    }
}

// 使用（自动携带 access_token）
webClient.get()
    .uri("http://inventory-service/api/stock/1")
    .retrieve()
    .bodyToMono(Stock.class);
```

## 总结

| 场景 | 推荐授权模式 |
|------|------------|
| 用户登录 Web 应用 | Authorization Code |
| 移动 App 登录 | Authorization Code + PKCE |
| 微服务间 API 调用 | Client Credentials |
| 第三方登录（微信/GitHub）| Authorization Code |
| 企业 SSO | OIDC（基于 Authorization Code）|
