# Java SPI 机制原理与实战

<div class="post-meta">📅 2024-12-07 &nbsp;·&nbsp; 🏷️ <span class="tag">Java</span> <span class="tag">设计模式</span></div>

SPI（Service Provider Interface）是 Java 内置的插件化机制，JDBC 驱动加载、日志门面、Spring Boot 自动装配都用到了它。掌握 SPI 有助于设计高扩展性的框架。

---

## 一、SPI 是什么

SPI 是一种**服务发现机制**：接口定义在框架中，实现由第三方提供，框架通过 `ServiceLoader` 自动发现并加载实现类，实现**接口与实现解耦**。

```
框架（接口定义）            第三方（实现）
┌──────────────┐          ┌──────────────┐
│  Interface   │◄─────────│    Impl A    │
│  定义服务接口 │          │  插件 A 实现  │
└──────────────┘          ├──────────────┤
                          │    Impl B    │
                          │  插件 B 实现  │
                          └──────────────┘
```

## 二、标准 Java SPI 实现步骤

### Step 1：定义接口

```java
// 消息发送接口（框架层定义）
public interface MessageSender {
    void send(String message);
    String protocol();
}
```

### Step 2：编写实现类

```java
// 实现一：HTTP 发送
public class HttpMessageSender implements MessageSender {
    @Override public void send(String message) { System.out.println("[HTTP] " + message); }
    @Override public String protocol() { return "http"; }
}

// 实现二：MQTT 发送
public class MqttMessageSender implements MessageSender {
    @Override public void send(String message) { System.out.println("[MQTT] " + message); }
    @Override public String protocol() { return "mqtt"; }
}
```

### Step 3：创建配置文件

在 `src/main/resources/META-INF/services/` 下创建以**接口全限定名**命名的文件：

```
文件路径：META-INF/services/com.example.spi.MessageSender

文件内容（每行一个实现类）：
com.example.spi.impl.HttpMessageSender
com.example.spi.impl.MqttMessageSender
```

### Step 4：通过 ServiceLoader 加载

```java
ServiceLoader<MessageSender> loader = ServiceLoader.load(MessageSender.class);

for (MessageSender sender : loader) {
    System.out.println("发现实现：" + sender.protocol());
    sender.send("Hello SPI");
}

// 输出：
// 发现实现：http
// [HTTP] Hello SPI
// 发现实现：mqtt
// [MQTT] Hello SPI
```

## 三、典型应用场景

### JDBC 驱动自动注册

```java
// 无需手动 Class.forName("com.mysql.cj.jdbc.Driver")
// MySQL 驱动包中有：
// META-INF/services/java.sql.Driver → com.mysql.cj.jdbc.Driver

Connection conn = DriverManager.getConnection(url, user, password);
// DriverManager 通过 SPI 自动发现并注册驱动
```

### SLF4J 绑定

SLF4J 门面通过 `META-INF/services/org.slf4j.spi.SLF4JServiceProvider` 发现 Logback/Log4j2 等具体实现。

### Spring Boot 自动装配（增强版 SPI）

Spring Boot 在标准 SPI 基础上实现了更强大的机制：

```
# Spring Boot 2.x：META-INF/spring.factories
org.springframework.boot.autoconfigure.EnableAutoConfiguration=\
  com.example.MyAutoConfiguration

# Spring Boot 3.x：META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports
com.example.MyAutoConfiguration
```

## 四、SPI 的缺点与改进

### 标准 SPI 的问题

1. **一次性加载所有实现**：无法按需加载，实现较多时有性能开销
2. **无法按名称查找**：只能遍历所有实现，不能指定加载某一个
3. **不支持依赖注入**：实现类需要无参构造器

### Dubbo SPI（增强版）

Dubbo 基于 SPI 设计了自己的扩展机制，支持按名称加载和 IOC：

```
# 配置文件：META-INF/dubbo/com.alibaba.dubbo.rpc.Protocol
http=com.alibaba.dubbo.rpc.protocol.http.HttpProtocol
dubbo=com.alibaba.dubbo.rpc.protocol.dubbo.DubboProtocol
```

```java
// 按名称获取指定扩展
Protocol protocol = ExtensionLoader
    .getExtensionLoader(Protocol.class)
    .getExtension("dubbo");  // 直接获取 dubbo 协议实现
```

## 五、自己实现一个简易 SPI

```java
public class SimpleServiceLoader<T> {
    private final Class<T> serviceType;
    private final List<T> services = new ArrayList<>();

    public SimpleServiceLoader(Class<T> serviceType) {
        this.serviceType = serviceType;
        load();
    }

    private void load() {
        String fileName = "META-INF/services/" + serviceType.getName();
        try (InputStream is = Thread.currentThread()
                .getContextClassLoader().getResourceAsStream(fileName);
             BufferedReader reader = new BufferedReader(new InputStreamReader(is))) {
            String line;
            while ((line = reader.readLine()) != null) {
                line = line.trim();
                if (!line.isEmpty() && !line.startsWith("#")) {
                    Class<?> implClass = Class.forName(line);
                    services.add(serviceType.cast(implClass.getDeclaredConstructor().newInstance()));
                }
            }
        } catch (Exception e) {
            throw new RuntimeException("加载 SPI 失败", e);
        }
    }

    public List<T> getServices() { return Collections.unmodifiableList(services); }
}
```

## 总结

| 维度 | Java SPI | Dubbo SPI | Spring factories |
|------|---------|-----------|-----------------|
| 配置位置 | `META-INF/services/` | `META-INF/dubbo/` | `META-INF/spring.factories` |
| 按名称加载 | ❌ | ✅ | ❌（按类型）|
| 支持 IOC | ❌ | ✅（自适应扩展）| ✅（Spring Bean）|
| 条件装配 | ❌ | ✅ | ✅（`@Conditional`）|

SPI 是 Java 生态扩展性的基石，理解它对阅读框架源码、设计插件化架构都有重要价值。
